# Laundry Mart

A modern and responsive Laundry Service website built using **HTML, CSS, and JavaScript**. The project allows users to browse laundry services, add them to a cart, calculate the total amount, and book services with email confirmation using **EmailJS**.

---

##  Features

- Responsive Home Page
- Fixed Navigation Bar
- Laundry Services List
- Add/Remove Services
- Dynamic Cart
- Automatic Total Amount Calculation
- Email Confirmation using EmailJS
- Booking Form
- Booking Confirmation Message
- Responsive Design

---

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- EmailJS

## Installation

1. Clone the repository

2. Open the project folder.

3. Open `index.html` in your browser.

---


## How It Works

1. Browse available laundry services.
2. Click **Add Item** to add services to the cart.
3. The cart updates automatically.
4. Total amount is calculated.
5. Fill in your:
   - Full Name
   - Email ID
   - Phone Number
6. Click **Book Now**.
7. A confirmation email is sent using EmailJS.
