## how to open/run

1. Clone the repository

```bash
git clone https://github.com/your-username/tailwind-hero-landing-page.git
```

2. Open the project folder.

3. Open `index.html` in any modern web browser.

> This project uses the Tailwind CSS CDN, so no installation or build process is required.
